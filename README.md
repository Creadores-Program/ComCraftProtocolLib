# ComcraftProtocolLib
ComcraftProtocolLib is a simple library for communicating with a Comcraft client/server. It aims to allow people to make custom bots, clients, or servers for Comcraft easily.

## Example Code
See [example/com/github/steveice10/comcraft/protocol/test/ComcraftProtocolTest.java](./example/com/github/steveice10/comcraft/protocol/test/ComcraftProtocolTest.java)

## Building the Source
ComcraftProtocolLib uses Maven to manage dependencies. Simply run 'mvn clean install' in the source's directory.
